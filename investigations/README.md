# IDMON Investigations

IDMON Investigations is a read-only Bitcoin intelligence and transaction-analysis track. It documents selected cases using reproducible on-chain evidence and keeps the boundary between verified facts, observed patterns, interpretation and attribution explicit.

Transaction movement alone does not establish a sale, a change of ownership or criminal activity. Where attribution or intent cannot be supported independently, it remains unresolved.

Investigation reports may use local Bitcoin Core data, retained IDMON archives and clearly identified external sources where applicable. Each case states its evidence provenance, reproducibility limits and unresolved questions.
